# Формирует словарь из текстовых файлов в каталоге.
наименование файла gen_dict.tcl
язык TCL, 
среда выполнения OSX


## Параметры:

- of|output - (необязательный) путь к выходному файлу (по умолчанию ./dict.tcl)
  - если файл существует, он будет перезаписан

- af|audio - путь к каталогу с .wav файлами
- df|definition - путь к каталогу с .txt или файлу dict.tcl
- обязательно установить хотя-бы один из параметров  af|audio или df|definition

- priority - (необязательный) приоритет обработки (audio|definition|dict), по умолчанию audio.
  - если dict, обязательно указывать dict

- dict=<путь к каталогу или словарь dict.tcl> - (необязательный кроме priority=dict) дополнительный словарь или каталог с текстовыми файлами (dict содержит более полную версию, в которой присутствуют избыточные данные ключ-значение и служит для поиска отсутствующих определений)

- report [=каталог] (необязательный) ключ указывающий на необходимость формирования отчета в каталоге (по умолчанию - в текущем каталоге)
- delete_wrong (необязательный) ключ указывающий на необходимость удаления файлов с неподдерживаемыми расширениями (по умолчанию - не удалять, но если указан report, тот выводить в него информацию о неправильных файлах)

## Логика работы
Анализирует параметр priority.
  - если priority=audio, выполняет рекурсивный поиск в каталоге af, отбирает все файлы с расширением wav.
   -- ищет в df файлы с наименованием совпадающим с наименованием найденных wav файлов в каталоге (или словаре) 
  - если priority=definition, выполняет рекурсивный поиск в каталоге df, отбирает все файлы с расширением txt.
   -- ищет в af файлы wav с наименованием, совпадающим с наименованием найденных txt файлов
  - если priority=dict или priority не задан, комбинирует оба вышеуказанных дейчтвия.

Формирует словарь ключ-значение из найденных результатов
  Например,
   -- af = ./test1
   ./test1 содержит подкаталогм cat_namespace1, cat_namespace2
   cat_namespace1 содержит файлы audio1.wav, audio2.wav, wrong_format_file.some_unknown_extension 
   cat_namespace2 содержит файлы audio1.wav, audio2.wav, audio3.wav, wrong_format_file.some_unknown_extension 
   -- df = ./test2
   ./test2 содержит подкаталогм cat_namespace1, cat_namespace2
   cat_namespace1 содержит файлы audio1.txt, audio2.txt, , audio3.txt, wrong_format_file.some_unknown_extension 
   cat_namespace2 содержит файлы audio1.txt, audio2.txt, wrong_format_file.some_unknown_extension

Если задан параметр dict, меняется логика заполнения значения в паре ключ-значение:
 - если priority= audio или text, сначала пытаемся найти значение в файлах txt, а если не удалось найти, то ищем в dict
 - если priority= dict, сначала пытаемся найти значение в dict, а если не удалось найти, то ищем в файлах txt

Если указан параметр report=<path> или --report, формирует текстовый файл "report.txt"

Если указан параметр "delete_wrong"
 - удаляет найденные файлы с расшрениями отличными от wav в каталоге af 
 - если df это каталог, а не словарь, то удаляет найденные в нем файлы с расшрениями отличными от txt

Если указан параметр "ignore_missing"
 - Когда подходящих пар не найдено, добавляьт в словарь пары ключ-значение с пустым значением 

## Форматы

### dict.tcl

```tclsh
global wordMap
set wordMap {
    "cat_namespace1" {
        "<наименование файла ./test1/cat_namespace1/audio1.wav без расширения>" {
            "<содержимое файла ./test2/cat_namespace1/audio1.txt>"
        }
        "<наименование файла ./test1/cat_namespace1/audio2.wav без расширения>" {
            "<содержимое файла ./test2/cat_namespace1/audio2.txt>"
        }
    }
    "cat_namespace2" {
        "<наименование файла ./test1/cat_namespace2/audio1.wav без расширения>" {
            "<содержимое файла ./test2/cat_namespace2/audio1.txt>"
        }
        "<наименование файла ./test1/cat_namespace2/audio2.wav без расширения>" {
            "<содержимое файла ./test2/cat_namespace2/audio2.txt>"
        }
    }
}
```
### report.txt
```txt
Неподдерживаемый формат файла ./test1/cat_namespace1/wrong_format_file.some_unknown_extension
Не найдена пара для файла ./test1/cat_namespace2/audio3.wav
Неподдерживаемый формат файла ./test2/cat_namespace1/wrong_format_file.some_unknown_extension
Не найдена пара для файла ./test2/cat_namespace1/audio3.txt
...

```

## Требования
- Файлы .wav и .txt должны иметь идентичные имена (кроме расширения)
- Кодировка текстовых файлов: UTF-8
- Максимальный размер текстового файла: 10MB
- Вложенность каталогов не ограничена

## Обработка ошибок
- При отсутствии обязательных параметров - завершение с кодом 1 и вывод поясняющего сообщения
- При ошибках чтения файлов - запись в отчет и пропуск файла
- При отсутствии прав - завершение с кодом 2 и вывод поясняющего сообщения

## Примеры использования
1. Базовый пример:
   ./gen_dict.tcl -af=./audio -df=./texts -of=./my_dict.tcl

2. С приоритетом audio и отчетом:
   ./gen_dict.tcl --audio=./wavs --definition=./txts --priority=audio --report
